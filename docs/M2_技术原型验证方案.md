window.Asc.plugin.callCommand(function () {

### 2.2 验证点 B 的基础：poi-tl / POI 动态建表已实现

`ConfirmMakeServiceImpl.java` + `WordManage.java` 已实现动态表格行生成：

## 三、验证方案

### 3.1 验证点 A：OnlyOffice 绑定落点定位

**目标**：确认能否在模板文档中"定位并标记某个表格位置"，作为后端渲染的锚点。

**候选方案（按优先度）**：

| 方案 | 实现 | 优缺点 |
|----|----|----|
| **A1：插件插入占位锚点标记** | 插件在文档光标/选中表格处，插入唯一占位文本 `[[SHEET_锚点_<id>]]`（放表格内或表格前后）；绑定关系记录"锚点 id ↔ 表格定位" | ✅ 简单可靠、后端易识别；⚠️ 锚点文本若留在最终 PDF 需清理 |
| **A2：书签（Bookmark）** | 用 OnlyOffice API 在表格位置插入书签，绑定记录书签名 | ✅ 更规范、不出现在正文；⚠️ 需确认 sdkjs 对表格书签的支持度 |
| **A3：定位当前选中表格** | 用户点表格 → 前端记录该表格的文档内序号/位置 → 绑定 | ✅ 直观；⚠️ 需能遍历文档表格并拿到稳定定位 |

**验证动作**：
1. 用现有插件通道，在 OnlyOffice 里尝试"选中一个表格后，在其位置插入一个占位标记/书签"；
2. 保存 docx，用 POI 读取，确认占位标记/书签能稳定定位到该表格；
3. 比较 A1/A2/A3 的可行性与稳定性，选最优。

**通过标准**：能在模板中插入唯一占位锚点，且后端 poi-tl/POI 能依据锚点准确定位到目标表格位置。

### 3.2 验证点 B：Excel Sheet 动态生成表格

**目标**：确认后端能把一个 Excel Sheet（任意列数/表头/数据）在模板"占位锚点"位置动态生成为一张完整 Word 表格。

**候选方案（按优先度）**：

| 方案 | 实现 | 优缺点 |
|----|----|----|
| **B1：POI 直接新建表格** | 在锚点位置，用 `XWPFDocument.createTable()` + 按 Sheet 首行建表头行 + 逐数据行 `createRow()` + 填单元格 | ✅ 完全按 Sheet 列数/表头动态生成、最贴合需求；⚠️ 需处理表格样式/宽度（可复用 `XWPFTableCellStyleCopier` / `HtmlToDocxConverter` 样式逻辑） |
| **B2：复用 `HtmlToDocxConverter`** | 把 Sheet 转成 HTML `<table>`，再用现有 `HtmlToDocxConverter.convertHtmlToDocx()` 生成 | ✅ 复用现有工具、自动处理表头/样式；⚠️ 需把"生成的表格"插入"已有模板的指定位置"而非新建文档 |
| **B3：poi-tl 表格模板 + LoopRow** | 模板预置一个 1 行的示例表格，用 poi-tl 按 Sheet 数据循环生成行 | ✅ 复用 poi-tl 机制；⚠️ 表头列数固定，不贴合"任意列数"需求 |

**验证动作**：
1. 取一个多 Sheet 的 Excel，解析表头+数据；
2. 在模板 docx 的锚点位置，分别用 B1/B2 尝试把 Sheet 生成表格；
3. 检查：列数=Sheet 列数、表头正确、**表格总宽=模板文本宽**、样式基本可用；
4. 选最优，并评估 B1 的列宽/样式控制、B2 的"插入到指定位置"改造难度。

**通过标准**：能在模板锚点位置生成与 Excel Sheet 列数/表头/数据一致、总宽对齐文本区的 Word 表格。

### 5.4 验证点 B 实测结果（2026-08-18）✅ 通过

**实现方式**：用 Python（`python-docx` 动态建表 + `openpyxl`/内存数据模拟 Excel Sheet），因为本机无 Maven + m2 无 poi-tl，Python 环境已就绪（docx/openpyxl/pandas 已装）。

**脚本**：`conversion_test/verify_B_sheet_to_table.py`
**产物**：`conversion_test/verify_B_output.docx`

**验证结果**：

| 验证项 | 结果 |
|----|----|
| 模板读取 | ✅ A4，文本宽度 5.77 英寸 |
| Excel Sheet 解析 | ✅ 表头 5 列 + 4 行数据 |
| 动态建表 | ✅ 模板新增 5x5 表格 |
| 列数一致性 | ✅ 表格列数 = Sheet 列数（5 vs 5） |
| 表头正确性 | ✅ 与 Sheet 第一行一致 |
| 数据填充 | ✅ 第 2 行数据正确 |
| **表格总宽=文本宽** | ✅ 8305 vs 8306 twips（差 1 twips，容差内） |
| 模板原有内容 | ✅ 段落数仍 34，表格 8→9，不受影响 |

**结论**：**验证点 B 完全可行**——能在 Word 模板中按 Excel Sheet 动态生成完整表格，列数天然一致、表头/数据正确、总宽精确锁定文本宽。Java/poi-tl 实现思路相同（POI `createTable()` 等价于 `python-docx add_table()`），M3 可照此落地。
